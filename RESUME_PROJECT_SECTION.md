### [ResuFit](https://frontend-drab-five-38.vercel.app) – AI Requirement Gap & Career Readiness Engine
**Stack:** Next.js 14, TypeScript, Node.js/Express, PostgreSQL, Prisma ORM, Docker, OpenAI LLM  
**Live Demo:** [frontend-drab-five-38.vercel.app](https://frontend-drab-five-38.vercel.app) | **GitHub:** [github.com/navsharma26/ResuFit](https://github.com/navsharma26/ResuFit)

- **AI-Powered Gap Analysis:** Automatically compares job requirements against resume experience chunks using OpenAI `gpt-4o-mini` with structured JSON output and a deterministic keyword fallback engine.
- **Evidence-Based Career Readiness:** Distinguishes between matched skills, missing mandatory skills, and nice-to-haves; generates actionable skill roadmaps and verifiable proof artifacts (Dockerfiles, READMEs, test suites).
- **Interactive Matrix & ATS Score:** Features dynamic radar/gauge visual match scoring, real-time filtering, drawer-based resume quote citations, and interactive completion tracking.
- **Production Cloud Architecture:** Dockerized microservices deployed on **Render** (Express backend) and **Vercel** (Next.js frontend) with high availability and proxy API routing.
